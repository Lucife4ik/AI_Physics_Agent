# ⚛️ AI Physics Agent — навчальний GenAI-агент

> **Навчальний проєкт з основ штучного інтелекту.** Інтерактивний AI-помічник для розв'язування фізичних задач із використанням великої мовної моделі (LLM) та власного інструмента обчислень.

## 🎯 Мета та завдання

Розробити GenAI-агента, який розуміє запити користувача, за потреби самостійно викликає Python-інструмент для обчислень і пояснює результат українською мовою.

| Вимога завдання | Реалізація |
|---|---|
| Використати LLM | Gemini API (`google-genai`) |
| Реалізувати хоча б один власний tool | `calculate_physics()` у `physics_tools.py` |
| Відповідати на запити користувача | Діалог з LLM та виклик інструмента |
| Створити простий UI або API | Вебінтерфейс на Streamlit |

## 🛠️ Технології

- **Python** — логіка програми та обчислення.
- **Gemini API** — обробка природної мови та вибір інструмента.
- **Streamlit** — вебінтерфейс, історія чату та приклади задач.
- **python-dotenv** — локальне зчитування налаштувань із `.env`.

## 🧠 Як працює агент

1. Користувач вводить запитання у вебінтерфейсі.
2. LLM аналізує запит і вирішує, чи потрібен інструмент.
3. Для підтримуваних числових задач LLM викликає `calculate_physics` із параметрами в одиницях SI.
4. Python-функція обчислює значення, повертає формулу, результат і одиниці вимірювання.
5. LLM формує зрозумілу відповідь українською мовою.
6. Користувач може переглянути журнал викликів інструмента.

## 📐 Підтримувані обчислення

| Фізична величина | Формула |
|---|---|
| Сила | `F = m · a` |
| Кінетична енергія | `Eₖ = m · v² / 2` |
| Імпульс | `p = m · v` |
| Швидкість | `v = s / t` |
| Робота (сила паралельна переміщенню) | `A = F · s` |
| Густина | `ρ = m / V` |

## 🚀 Запуск у VS Code (Windows)

**1.** Відкрийте папку проєкту у VS Code.

**2.** Встановіть залежності в терміналі:

```powershell
python -m pip install -r requirements.txt
```

**3.** Створіть локальний файл `.env` на основі `.env.example`:

```dotenv
GEMINI_API_KEY=YOUR_API_KEY_HERE
GEMINI_MODEL=YOUR_AVAILABLE_MODEL_NAME
```

Отримати ключ можна в [Google AI Studio](https://aistudio.google.com/apikey). Назву моделі потрібно вказати відповідно до доступних моделей вашого API-проєкту.

**4.** Запустіть застосунок:

```powershell
python -m streamlit run app.py
```

**5.** Відкрийте [http://localhost:8501](http://localhost:8501).

> ⚠️ **Безпека:** файл `.env` містить секретний API-ключ. Він включений до `.gitignore` і **не повинен потрапляти до GitHub**. Якщо ключ випадково оприлюднено, його потрібно відкликати й створити новий.

## 🧪 Приклади тестування

| Запит | Очікуваний результат |
|---|---|
| Сила для 10 кг та 5 м/с² | **50 Н** |
| Кінетична енергія для 5 кг та 10 м/с | **250 Дж** |
| Швидкість для 150 м за 10 с | **15 м/с** |

Числові відповіді отримуються за допомогою власного інструмента, а LLM пояснює результат. Для роботи потрібен доступ до інтернету та доступна квота Gemini API.
